SGAS Web - NEHARI.A
خطوات النشر:
1. ارفع app.py و requirements.txt و render.yaml إلى مستودع GitHub جديد.
2. أنشئ حساب Render واربطه بمستودع GitHub.
3. اختر New ثم Blueprint واختر المستودع.
4. عند طلب SGAS_PASSWORD ضع كلمة مرور قوية لا تشاركها.
5. ابدأ النشر. بعد نجاحه ستحصل على رابط HTTPS عام.
6. إعداد Render يربط قاعدة SQLite بقرص دائم /var/data.

تنبيهات:
- إعداد Render يستخدم خطة Starter وقرصاً دائماً؛ تحقق من التكلفة قبل الموافقة.
- لا ترفع قاعدة بيانات تحتوي بيانات شخصية إلى GitHub.
- كلمة مرور واحدة مشتركة للمشرفين في هذه النسخة، وليست نظام حسابات وصلاحيات فردية.
- اختبر المنصة ببيانات تجريبية قبل إدخال بيانات حقيقية.
- لا تتضمن هذه النسخة الشعار الرسمي لعدم توفر ملف صورة موثوق.
